# dashboard-shell

Wave 1 operator-facing application.

## Purpose

`dashboard-shell` owns navigation, filters, identity-aware action routing, and surface composition for hosted Prophet Platform apps.

## Initial pages

- Overview
- Deep-Dive Reports
- Queue Operations

## Later pages

- Physical Map
- Logical Topology
- Artifact Browser
- Topology Explorer

## Rule

The shell owns navigation and composition. Heavy service logic remains in backend services and integrations.
