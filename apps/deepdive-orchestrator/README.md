# deepdive-orchestrator

Wave 1 hosted platform service.

## Purpose

This service coordinates deep dives across repositories, environments, artifacts, rooms, and cases.

## Inputs

- search evidence
- case state
- identity and policy state
- topology and environment data
- artifact and release metadata

## Outputs

- structured analytic dossiers
- findings
- remediation backlogs
- evidence-linked reports
- traceable deep-dive runs
